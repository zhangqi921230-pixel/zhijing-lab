弧度与弧长（6节）

圆弧展开 → 接近1弧度 → 半圆与π → 整圆与2π → 同角不同半径 → 等弧长的不同圆心角。利用三圆同尺度对照，区分固定角度时的正比关系与固定弧长时的反比关系。先预测弧长，再播放等长展开，改变半径检验 s=rθ。

拍频与振动叠加（6节）

同频加强 → 近频拍 → 频差与拍周期 → 不等幅的谷底 → 单振动极限 → 加强时的瞬时过零。用冻结时刻的同标尺位移箭头和包络半高，区分瞬时位移为零与相互抵消。观察分量与合成位移，区分振幅包络和实际振动；图示低频不是可听声音。

月相第五节：等亮面不等于同月相

同时比较θ与360°−θ的月面、亮面比例和各自再前进15°后的状态。通过切换对照联动轨道与曲线，区分盈亏方向；新月和满月为同一对照的边界情况。月面朝向采用北半球常见示意。

如何组织一次探究

返回目录 ↑
  1. 先看问题，提出自己的预测。
  2. 记录初始状态，每次只改变一个变量。
  3. 比较数据或现象，尝试解释。
  4. 展开模型假设，讨论现实中哪些条件不完全符合。

遗传概率：五节递进探究

返回目录 ↑
  1. 配子与组合：点选方格，将两个亲本提供的等位基因组合成子代。
  2. 杂合子互交：比较 AA、Aa、aa 的理论概率，区分基因型与表现型。
  3. 用测交辨别：分别设置 AA×aa 和 Aa×aa，解释不同预测。
  4. 少量后代的随机波动：两次各抽样 20 个，观察结果不必相同。
  5. 样本量与概率证据：连续抽样至 1000 个，对照理论柱与频率柱，讨论“未观察到”与“不可能”的区别。

抽样使用单基因完全显性模型，每次独立选取两个配子。课堂样本为临时演示，切换亲本、章节或复位会清空，不写入实验记录；可暂停后讨论。进入遗传工作台 →

食物链能量：五节递进探究

返回目录 ↑
  1. 逐级传递：点选草、兔、狐，核对各级能量。
  2. 效率与累积差异：固定起点，比较10%、15%、20%的末级结果。
  3. 能量账本：两次未传递份额与狐获得量合计等于起点能量。
  4. 两级效率相乘：说明15%×15%=2.25%，区分乘法与相加。
  5. 未传递部分的去向：讨论呼吸、碎屑和分解途径，区分能量流动与物质循环。

动物剪影只标识营养级，不按能量或生物量缩放。进入能量流动工作台 →

光合作用：五节控制变量探究

返回目录 ↑
  1. 光照：固定 CO₂ 和温度，扫描相对光照。
  2. CO₂：保持光照充足，对照低与高供给。
  3. 温度：固定其余条件，观察模型温度响应。
  4. 共同限制：保存低 CO₂ 的光照响应曲线，只改变 CO₂，比较虚线与实线。
  5. 证据边界：讨论控制变量、模型预设最适温度，以及总光合与净光合的区别。

扫描速度不是植物响应时间，曲线为定性模型而非实测数据。进入光合作用工作台 →

生态样方：五节比较探究

返回目录 ↑
  1. 清点示例种：俯视核对四类假想示例种。
  2. 均匀度：比较均匀分配与优势种情境。

流域水量：从路径到守恒

返回目录 ↑
  1. 降水分配：辨认地表径流、下渗与蒸散。
  2. 下渗与径流：固定降水和蒸散，扫描下渗比例。
  3. 蒸散与平衡：检查各分量之和。
  4. 同一场雨：保留对照 A，再用滑块改变下渗，比较差值。
  5. 比例与总量：降水加倍时比例条不变，而各分量水量加倍。

扫描是参数演示，不是暴雨或洪峰预测；植被显隐不改变下渗参数。进入流域工作台 →

地震波：从地下位置到到时证据

返回目录 ↑
  1. 震源与震中：改变深度，辨认地下位置与地表投影。
  2. P波与S波：对照质点振动方向、波前和路程—时间直线。
  3. 到时差与距离：用剖面三角形区分震中距和震源距。
  4. 两次到达之间：定位并暂停，对照台站与波前。
  5. 单台站边界：两组不同位置具有相同50km震源距，比较到时不变。

火山：结构、喷出物与过程

返回目录 ↑

  2. 喷发形态：在相同8秒演示时刻比较溢流式与爆发式。

分数：从等分到比较

返回目录 ↑
  1. 整体与等分：同一个整体分成不同份数，观察每份大小。
  2. 等值分数：比较1/2、2/4和4/8，同尺度分数条覆盖量保持相同。
  3. 跨过一个整体：联动圆盘与数轴，比较7/8、8/8和9/8。
  4. 同分母比较：保留3/8为A，再调分子观察份数增加。
  5. 同分子比较：保留3/4为A，再调分母到8，观察每份变小。

比较始终以同样大小的整体为单位，乘法核对可按教学进度展开。进入分数工作台 →

勾股定理：从拼图到证明

返回目录 ↑
  1. 识别三个正方形与直角三角形的边。
  2. 刚性移动四块全等三角板，对照两种端点拼法。
  3. 改变直角边长，验证各面积读数。
  4. 按底板、三角板、剩余面积的顺序解释(a+b)²−2ab=a²+b²=c²。
  5. 同比放大：边长加倍，各块面积变为四倍，关系仍成立。

以起点与终点核对面积分割，移动中的投影可能重叠。进入勾股工作台 →

圆：从测量到逼近

返回目录 ↑
  1. 展开圆周绳，用直径尺理解C/d=π。
  2. 等分圆盘并交错重排，保留真实圆弧。
  3. 改变半径，对照周长的一次关系与面积的平方关系。
  4. 放大比较8、16、32、48等分的弧高，观察边缘变平。
  5. 拓展：比较内接多边形与圆的面积差，区分完整扇形等积重排与多边形近似。

最后一步为进阶拓展，不要求小学阶段掌握三角函数公式。进入圆的工作台 →

新增：波动与浮力

返回目录 ↑

波的传播与叠加：振动与传播 → 波速、波长与频率 → 相长 → 相消 → 驻波与波节。高中拓展以三条同尺度曲线展示位移叠加，播放与时间轴共用一个时钟。

浮力、排水与沉浮：浸入与排水 → 液体密度 → 区分物重与浮力 → 漂浮排水比例 → 漂浮、悬浮和沉底。初中阶段通过受控浸入及最终平衡对照，不把静态结果呈现成未经计算的落水过程。

正方体：从六个面到逐层填满

返回目录 ↑

折叠十字展开图 → 追踪相对面 → 改变棱长 → 给每个面分格 → 用小方块逐层填满。面内n²格对应面积，每层n²块、共n层对应体积；等分数变化不改变整个正方体的表面积与体积。

课堂可先问“第二层填完有几块”，再点击层按钮或播放检验；小方块不一定是1cm³，须结合a/n计算。进入正方体工作台 →

面积剪拼与液压机：看得见的守恒

数学五步：辨认底与垂直高度 → 剪下三角形 → 平移补齐 → 改变倾斜 → 改变高度。先预测面积，再播放验证 S=bh。金色块保持形状，先向下移出、再向右平移、最后向上归位，两块内部不重叠。用“原图与剪切线、移出三角形、平移到右侧、归位成矩形”四个按钮逐步讲解，比较搬运前后的面积。

物理五步：同面积传力 → 不同面积放大力 → 等体积位移 → 输入输出功 → 改变施力。以 A₁=10 cm²、面积比4、输入40 N为例，输出160 N；输入行程8 cm对应输出2 cm，机械功均3.2 J。讨论为什么不能同时放大力和位移。

NIST 钠强谱线表

先预测，再换高倍

在显微镜“先居中，再换高倍”章节展开视野范围并开启教学参考点。准备偏心状态，比较40、100、400倍并排图，预测目标是否仍在视野内；切换倍率核验，再将参考点居中重复观察。金色点是教学坐标标记，不是特定细胞。

多台站：同一时刻的不同接收状态

先播放地震波传播，比较三个台站何时先后接收P波、S波；按台站按钮定位到精确到时，再看上方A台站与下方三站的状态差别。定位圆使用完整理论到时差，不代表播放到当前时刻已取得所有观测。均匀介质模型采用P波6 km/s、S波3.5 km/s。

圆柱展开与光的三原色

圆柱展开：侧面展开→两个底面→半径变化→高度变化→无盖容器。先预测尺寸改变的结果，再调参核对面积；评价任务：解释半径加倍时表面积为什么不一定加倍。

三原色色光：三束光相遇→红绿混合→青与品红→中性灰白→互补色。播放光斑靠近，对照关闭各通道前后颜色；使用六组快捷组合比较双色、中性白、25%中性灰与全暗，随后只调整一个通道，记录偏色变化；评价任务：比较光的混合与颜料混合，说明屏幕 RGB 模型的适用边界。

同一场径流，不同输入历时

先固定0.5小时输入作为参照，再切换到4小时；比较出流峰值和同一时刻出流率。解释为何最终累计出流水量相同，峰值却不同；辨认12小时处仍保留的暂存水量。对照只固定历时，不保存另一场雨的水量。

齿轮与浮力：从观察到定量解释

齿轮传动与转速比（15分钟）

先追踪标记判断两轮转向；再比较12/36、36/12和24/24齿组合；最后固定齿数调节输入速度，使用n₁z₁=n₂z₂核验。使用“通过6个齿距”定位，比较两轮转数乘以各自齿数，解释为何通过距离相同。提问：为什么小轮转得快？轮齿形状为教学示意。

称重法测浮力（15分钟）

从空气缓慢浸入，暂停在半浸没与完全浸没状态；比较4到6秒的浮力，再固定体积改变液体和物体密度，核验T+F浮=G。使用四个称重观察位置，将空气参考减去当前示数；再用液体密度、g与排水体积交叉验证，注意cm³到m³的换算。学生说明浮力与排水体积的关系，区分悬吊浸入和自由漂浮。

圆柱面积：单变量对照

固定r=1 cm、h=2 cm为参照，分别将半径或高度加倍。先观察同尺度面积条，再比较侧面、底面与总面积的倍数。说明为何半径加倍不意味着总表面积只变为两倍；最后对照无盖容器减去的面积。

显微镜细调：试调与反向

在寻找与调焦、高倍观察中先看目镜，再细调2格。根据模拟物像变清晰或变模糊决定是否继续同向，必要时反向。照明不足时先对光，换倍率后重新比较；不要把模拟旋钮数值当作真实镜头位移。

降水去向：读水带与流向

先静态比较三条水带的宽度，再播放流向演示，逐项突出径流、下渗和蒸散。短线仅帮助辨认去向，不能用移动速度判断流量；将降水调为0检查水带和短线同时消失。

焰色拓展：固定波长观察展宽

在钠双线图中将探针放到两线中点，比较“混在一起”和“清晰分开”的响应。再定位到各谱线，解释线的位置不变而展宽改变分辨效果；归一化曲线不能用于比较样品浓度。

光合作用：相同加光量，不同速率增量

固定CO₂与温度，分别观察光照10%到30%、70%到90%的模型速率变化。比较增加的百分点，说明曲线趋缓不等于从某个固定光照值起完全不变；再将CO₂设为0，讨论为什么仅加光无效。

概率：同组次比较两轮频率

保留一轮并重新试验，用组次探针比较两轮同一组次的累计频率。寻找偏差变大和变小的相邻位置；解释为什么频率通常趋近理论值，不等于每追加一组都更接近。

新增：转一圈与留一道缝

多边形外角与行走转向：三角形→正方形→五边形内外角→增加边数→反向行走。先预测每次转角，再播放或定位进度，最后用累计360°核对。

固体热膨胀与伸缩缝：材料比较→温差关系→长度关系→降温缩短→接缝抵接。一次只改变一个条件，记录三种材料的毫米伸长，说明为什么自由伸长公式不能预测抵接后的实际变形。图中变形放大200倍，非真实工程设计工具。

热膨胀：从动画到关系图

保持杆长与接缝不变，依次观察0、30、60°C温差，比较自由伸长。再观察−30°C，解释负值。由曲线与接缝水平线的交点预测抵接温差；区分自由伸长需求与接触后的实际位移。

地震定位：证据何时足够？

选择三个台站并开启“跟随到站进度”，先定位A台站P波：观察位置已知，但距离尚不可计算。再定位各台站S波，记录何时出现第一、第二、第三道距离圆。把A台站移远，观察B、C先提供约束的情形。最后切回完整理论模式，解释距离圆与传播波前的区别。

新增探究：面积恒等式与双源干涉

平方差与面积拼接：去掉小正方形 → 分成两块 → 旋转 → 拼成长方形 → 改变边长。建议先预测面积，再播放并用两种方法计算；重点区分长度单位与面积单位。

双源水波与干涉：等距加强 → 半波程差抵消 → 整波程差加强 → 反相波源 → 改变波长。先看两分量，再看合成曲线；模型为等振幅稳态，不能据此推断真实水波能量分布。

水波进阶：空间条纹与时间振动

进入双源水波第6节，固定纵坐标8厘米，以1厘米步长移动探针。先预测中线的合振幅，再对照底色和位置—振幅曲线。保持观察点，播放并比较上方位移—时间曲线；说明为什么底色不随波峰向外移动。将波源相位改为180度，检查原来加强的中线是否变为抵消。

底图为有限网格示意，精确振幅由解析式计算；本模型等振幅、无衰减，不用于计算真实水波能量通量。

平方差：从边长读出因式

依次点选原始面积、平移完成、旋转完成、拼接完成。先在原图找出a−b与b，再在终图找出总长a+b和共同高度a−b；用颜色对应a(a−b)与b(a−b)两项，最后提取公因式。设置a=8、b=1，追踪长条旋转；设置a=4、b=3，观察窄条拼接。长度与面积使用不同单位，移动和旋转保持的是面积。

置换反应：从金属表面到物质去向

切到三维器材，选择观察金属表面，依次定位反应前、中间过程、完全反应。对照铁、锌、铜片，区分原金属与新析出的铜；减少投入质量，观察原片耗尽而铜仍保留。使用复位视角返回全套装置。表面纹理与铜颗粒只辅助观察，不代表真实晶体尺寸、腐蚀形貌或反应速度。

光合作用第6节：净光合不是总光合

保持CO₂供给和温度，另给定恒定呼吸消耗R。先观察黑暗下P=0、净光合为−R，再提高光照并定位P=R的补偿点；解释为什么净光合为零不表示光合作用和呼吸都停止。将CO₂供给降到2%，观察在当前光照范围内可能没有补偿点。曲线均为相对量教学模型，不能用于推断真实植物的呼吸、生长或补偿点。

弧度与弧长（6节）

圆弧展开 → 接近1弧度 → 半圆与π → 整圆与2π → 同角不同半径 → 等弧长的不同圆心角。利用三圆同尺度对照，区分固定角度时的正比关系与固定弧长时的反比关系。先预测弧长，再播放等长展开，改变半径检验 s=rθ。

拍频与振动叠加（6节）

同频加强 → 近频拍 → 频差与拍周期 → 不等幅的谷底 → 单振动极限 → 加强时的瞬时过零。用冻结时刻的同标尺位移箭头和包络半高，区分瞬时位移为零与相互抵消。观察分量与合成位移，区分振幅包络和实际振动；图示低频不是可听声音。

月相第五节：等亮面不等于同月相

同时比较θ与360°−θ的月面、亮面比例和各自再前进15°后的状态。通过切换对照联动轨道与曲线，区分盈亏方向；新月和满月为同一对照的边界情况。月面朝向采用北半球常见示意。
