# 知境 · 互动教学实验室

多学科互动课程与仿真实验。

## 本地运行

需要 Node.js 24。执行 npm ci、npm run dev。

## 发布

main 分支更新后，GitHub Actions 自动构建并发布 GitHub Pages。仓库 Pages 设置应使用 GitHub Actions。

公开版建议与许愿保存在本仓库 Issues，提交需要 GitHub 账号。首页读取最新30条建议和许愿进行展示。课程点赞需要数据库后台，Pages 版暂未开放。GitHub Pages 的中国大陆网络可用性需实际测试，无法保证所有地区稳定。

本地版本使用 SQLite 保存社区记录，数据库不提交到仓库。
