# 知境 · 互动教学实验室

**让理解，看得见。**

知境是面向教师课堂演示与学生自主探究的多学科互动教学网站。把抽象的公式、看不见的过程和难以想象的空间关系，变成可以观察、操作和比较的实验，让学生在“动手改变—观察现象—解释原因”的过程中建立理解。

[在线体验](https://zhangqi921230-pixel.github.io/zhijing-lab/) · [建议与许愿](https://zhangqi921230-pixel.github.io/zhijing-lab/#community) · [课程依据与模型边界](https://zhangqi921230-pixel.github.io/zhijing-lab/curriculum.html)

## 科普馆：从生活里的问题开始

本地版本新增独立科普馆（`#science`），覆盖 **12 个领域、120 个可阅读编辑稿主题**。从天空与海水的颜色，到火箭、空调的内部结构，再到春花与蝶蛾辨识，每题包含分步讲解、专属图解或实拍对照、观察操作、理解检查及资料来源。

火箭和空调采用写实剖面图，结构名称与短说明由网页标注；手机上说明移到图下，打印版也保留编号与解释。支持搜索、分类、24 项一页的主题浏览、本机收藏与继续阅读。24 个主题设有重点互动，8 个主题提供可点选的三维教学结构；三维按需加载，二维内容始终可读。

这批内容尚待独立科学编审与真实课堂试用，三维模型为教学简化模型。照片的作者、物种与许可单独记录；其中部分图片限制非商业使用，详情见 [科普素材来源](public/science/SOURCES.md)。本地新增内容不表示已同步到上面的在线体验地址。

## 项目特色

### 让知识产生可见的变化

课程以动态模型和互动实验为核心。改变参数、切换条件、调整视角，画面随之变化：看山体如何对应等高线，看两列波怎样叠加，看溶质与晶体的变化。二维图解与三维场景结合，帮助连接概念、图像和空间关系。

### 从一个问题开始，逐步深入

学习内容按章节组织，将观察任务、操作步骤、知识解释与模型边界放在同一学习情境中。教师可以按教学进度选择章节，学生也可以围绕具体问题反复尝试。不同实验提供相应的参数控制，部分主题支持暂停、单步、回放、时间轴或数据记录，便于抓住关键瞬间进行讨论。

### 同样的实验，试出不同的结果

通过条件对照和实时反馈，把“记住结论”转化为“解释变化”。例如调整透镜相关参数观察成像，改变波的条件比较叠加现象，切换种子萌发实验条件寻找必要因素。互动模型为提问、预测、验证和解释提供共同的观察对象。

### 为课堂展示，也为课后探索

- **快速找课**：按学科、学段、基础内容筛选，或搜索知识点；主题卡片提供动态预览。
- **清晰展示**：支持浅色、深色外观，结合图解、读数与说明呈现关键现象。
- **手机也能操作**：学科两行平铺，学段紧凑显示；章节选择器和底部快捷导航帮助定位实验、播放与参数。
- **减少画面遮挡**：手机端隐藏预览状态角标，保留动画及实际播放控制。
- **按需使用动态效果**：预览支持暂停，离屏或后台时停止相关动画；首页地形使用课程三维模型自动环视，并尊重系统的减少动态效果偏好。

### 和老师一起把课程做得更好

“建议与许愿”让教学中的真实需求进入项目迭代：既可以指出当前主题的问题，也可以提出新主题名称、希望实现的操作和期望呈现的效果。反馈记录便于发现其他老师的想法，逐步形成可追踪的共建记录。当前公开版暂时隐藏站内反馈速览，可通过反馈入口查看完整记录。

## 怎样用于教学

1. **课前备课**：按学科和学段选取主题，提前体验章节与参数，确定本节课的观察问题。
2. **课堂引入**：展示一个现象，请学生先预测改变条件后的结果。
3. **共同探究**：调整一个变量，比较画面和读数；必要时暂停、回放，组织学生解释。
4. **课后巩固**：学生用同一主题重复实验，比较不同条件，记录自己的发现。
5. **持续共建**：将课堂中发现的问题或新教学设想提交到“建议与许愿”。

建议在实际教学设备和网络上提前打开课程。三维场景需要浏览器支持 WebGL，流畅程度取决于设备性能；复杂的辅助图表可能需要局部滚动。

## 提交建议与新主题许愿

欢迎从具体教学场景出发，说明：

- **主题名称**：希望改进的现有主题，或希望新增的主题。
- **实现要求**：适用学科与年级、课堂问题、希望支持的操作或对照条件。
- **呈现效果**：希望学生看到什么现象、理解什么关系、达成什么学习目标。

当前在线版通过 GitHub 表单提交反馈，需要登录 GitHub；记录保存在仓库 Issues，可通过反馈页面的链接查看。公开版暂未开放主题点赞。自建完整服务支持站内提交和点赞，内容保存到服务端 SQLite 数据库。两种方式的数据不自动同步。

反馈公开可见，请勿填写学生个人信息。建议会结合教学价值与实现条件进行评估；记录关闭不代表功能已经实现。项目当前未启用定期自动优化任务。

## 本地体验与开发

项目使用 **React、Vite、Three.js**，结合 SVG 与三维场景实现教学交互；完整社区服务使用 Node.js 和 SQLite。

推荐 Node.js 24，最低版本为 22.13.0。

```bash
git clone https://github.com/zhangqi921230-pixel/zhijing-lab.git
cd zhijing-lab
npm ci
npm run dev
```

打开终端提示的本地地址。构建并运行完整服务：

```bash
npm run build
npm start
```

Windows PowerShell 如阻止执行 `npm.ps1`，可使用 `npm.cmd`。完整服务的社区数据默认保存在 `data/community.sqlite`，更新或迁移时请单独保留数据目录。
